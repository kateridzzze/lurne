# Lurne — дизайнерские зимние куртки

> Демонстрационный / учебный проект.

**Бренд, названия и изображения являются вымышленными и созданы с использованием ИИ.**

---

## О проекте

**Проблема:** позиционирование бренда одежды в интернете, увеличение конверсии и привлечение аудитории через лендинг.

**Цель:** создать сайт-визитку бренда дизайнерских зимних курток, который:
- презентует бренд и коллекцию;
- формирует доверие через технологии и детали;
- собирает заявки на предзаказ через форму обратной связи.

**Основная функция** — конверсия посетителей в заявки (лидогенерация).

---

## Функционал

### Реализовано
- **Главная страница** — Hero, о бренде, коллекция курток, технологии, процесс создания, форма предзаказа
- **Страница товара** — галерея, описание, характеристики, выбор размера
- **Юридические страницы** — политика конфиденциальности, согласие на обработку ПДн (152-ФЗ)
- **Анимация снега** — Canvas 2D, символы + SVG снежинки, оптимизация `will-change` и `prefers-reduced-motion`
- **Reveal-анимации** — появление секций при скролле (IntersectionObserver)
- **Модальное окно предзаказа** — с фокус-ловушкой и закрытием по Esc
- **Адаптивная вёрстка** — 12/8/6/1 колонок, mobile-first
- **Форма обратной связи** — Яндекс.Формы (iframe)
- **SEO** — семантическая разметка, Open Graph, Twitter Card, JSON-LD Product

### Технологии
- HTML5, CSS3 (кастомные свойства, CSS Grid, Flexbox)
- Vanilla JavaScript (ES6+)
- Canvas 2D API (анимация снега)
- IntersectionObserver API (reveal)
- Яндекс.Формы (интеграция формы)

### Не реализовано (за пределами ТЗ)
- CMS, корзина, платёжная система
- Аналитика
- Многоязычность
- Деплой и хостинг
